# Implementation notes: ab-compare

## Верхняя плашка: µs печатались как ms (ui.rs)
- Planned: спека касалась только новой A/B-таблицы.
- Found: в существующей строке статистики p50/p99 (значения в µs) печатались как `"{p50:.2} ms"` без деления на 1000 — баг отображения, подтверждён вердиктом (п.3.1).
- Did instead: исправил верхнюю плашку (деление на 1000) + конвертация в новой таблице.
- Why: требование вердикта «попутно исправить верхнюю плашку».

## ETW-режим не проходит через live::worker (etw.rs)
- Planned: спека предполагала «в ETW будет заполнена только OFF-сторона», не уточняя механизм.
- Found: в ETW-режиме воркер live.rs не запускается; более того, заголовочная строка FPS/p50/p99 в ETW всегда была 0.0 (ETW-колбэк заполнял только samples для графика).
- Did instead: в колбэке etw.rs — троттлинг 20 мс (Arc<Mutex<Instant>>, безопасно и для Fn-колбэков) + публикация compute_side_stats в stats.off и в заголовочную строку.
- Why: требование вердикта (п.3.2) + устранение старого пробела (ETW-статистика была нулевой).

## Дедуп percentile (live.rs, watch.rs)
- Planned: «алгоритм перцентилей унифицировать с watch.rs».
- Found: percentile дублировался приватной копией в watch.rs.
- Did instead: live::percentile → pub(crate), watch.rs импортирует его, локальная копия удалена.
- Why: одна реализация перцентиля на оба пути отображения.
