# All In Frame (AIF)
### Universal Asynchronous Mouse Warp (AMW) & Predictive Frame Synthesizer

> **Новая веха в графических технологиях:** Первый в мире фреймворк, реализующий аппаратный Asynchronous Timewarp (известный по VR-шлемам) на плоских ПК-мониторах, совмещённый с предиктивной экстраполяцией кадров без добавленного инпут-лага.

---

## 💡 В чём революция All In Frame?

Существующие генераторы кадров (**Nvidia DLSS 3/4 Frame Generation**, **AMD FSR 3**, **Lossless Scaling LSFG**) работают по принципу **интерполяции**:
```
Кадр N ➔ [Ожидание рендера кадра N+1] ➔ Интерполяция N.5 ➔ Задержка +15...30 мс!
```
Это делает картинку визуально плавной, но управление мышью становится «ватным» и заторможенным.

**All In Frame** переворачивает этот принцип:
1. **Asynchronous Mouse Warp (AMW):** Приложение перехватывает сигналы мыши с частотой **1000 Гц** через Raw Input.
2. За **0.5 мс до VBlank** монитора Compute Shader на лету выполняет 3D-репроекцию последнего отрендеренного кадра по буферу глубины (Z-Buffer) на точный угол поворота мыши.
3. **HUD Isolation Engine:** Прицел, шкалы здоровья и миникарта алгоритмически отсекаются по маске глубины и остаются статичными и монолитными.
4. **Результат:** Даже при 30–45 FPS рендеринга игра управляется с отзывчивостью **240 Гц киберспортивного монитора с задержкой < 1 мс**!

## 🏗 Архитектура проекта

Рабочее пространство состоит из 5 специализированных модулей:

* **`crates/aif-common`**:
  * Математика 3D-проецирования и обратного проецирования (Unproject/Reproject).
  * Преобразования матриц поворота камеры и кватернионов по дельте мыши.
  * Линеаризация стандартных и Reverse-Z буферов глубины.
  * Высокочастотный кольцевой трекер Raw Input (`InputAccumulator`).
* **`crates/aif-warp`**:
  * HLSL Compute Shader (`cs_5_0`), выполняющий преобразование 3D View Space ➔ Rotation ➔ Screen Space.
  * Двустороннее взвешенное сэмплирование и заполнение скрытых зон (Edge Inpainting).
  * Direct3D 11 пайплайн выполнения шейдера (`WarpPipeline`).
* **`crates/aif-hook`**:
  * Внедряемая библиотека (`aif_hook.dll`).
  * VMT перехватчики `IDXGISwapChain::Present` и `Present1`.
  * Автоматический захват буфера глубины активной 3D-сцены (`DepthTracker`).
* **`crates/aif-app`**:
  * Панель управления и дашборд (`all-in-frame.exe`) на базе `egui`.
  * Выбор целевого процесса, инжектор DLL, настройка чувствительности мыши, угла обзора (FOV), Reverse-Z и множителя генерации кадров.
* **`crates/aif-demo`**:
  * Собственный 3D-тестовый стенд (`aif-demo.exe`) с вращающейся 3D-геометрией, активным Z-буфером, неподвижным прицелом и симуляцией тяжёлой игры на 30 FPS.

## 🚀 Быстрый старт и проверка

### 1. Сборка проекта
```bash
cargo build --release
```
Все исполняемые файлы будут скомпилированы в папку `target/release/`:
* `all-in-frame.exe` — Панель управления.
* `aif_hook.dll` — Модуль перехвата и репроекции.
* `aif-demo.exe` — 3D-демо со встроенным ограничением 30 FPS.

### 2. Тестирование на 3D Benchmark Demo
1. Запустите тестовую сцену:
   ```bash
   target\release\aif-demo.exe
   ```
   *Вы увидите 3D-сцену, залоченную на 30 FPS.*
2. Запустите приложение управления:
   ```bash
   target\release\all-in-frame.exe
   ```
3. В выпадающем списке выберите окно **All In Frame — 3D Benchmark Demo** и нажмите **«Подключить All In Frame в процесс»**.
4. Попробуйте подвигать мышью: камера реагирует мгновенно на полной герцовке вашего монитора, а прицел остаётся стабильным!
